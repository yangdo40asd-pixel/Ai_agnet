## 1. 프로젝트 개요 및 목적 (WBS `D9`, `D10`)

### 1.1 프로젝트 정의 (`D9`)
본 프로젝트는 **사용자가 관심 있는 산업·주식 테마를 입력하면 AI가 관련 상장 종목 후보 3개를 제안하고, 공식 KRX 상장 목록과 대조한 뒤 사용자가 선택한 종목에 대해 핵심 투자 지표(주가·PER·PBR·ROE·EPS·BPS), 일별 주가·거래량 추이, OpenDART 기업 재무제표(손익·재무상태·현금흐름), 최신 뉴스 및 근거 기반 AI 해석을 한 화면의 대시보드와 편집 가능한 엑셀(XLSX) 파일로 제공하는 분석 서비스**입니다.

전체 서비스 표준 흐름은 다음 6단계로 구성됩니다:
1. **테마 입력**: 사용자의 관심 테마 키워드 입력 및 입력값 정규화·유효성 검사
2. **후보 탐색 및 상장 확인**: AI 후보 3개 제안 → KRX 상장 종목 목록 정확 대조(6자리 종목코드·시장·조회 티커 확인, 미확인 시 1회 재제안)
3. **사용자 분석 종목 선택**: 상장 및 지원 시장이 확인된 후보 중 사용자가 분석할 대표 종목을 직접 선택 (선택 전에는 대기 상태 유지)
4. **다중 데이터 수집·표준화**: 선택 종목의 주가·밸류에이션 지표, 일별 주가·거래량 이력(OHLCV), OpenDART 재무제표·수익성 지표, 관련 뉴스 제목·원문 링크 수집
5. **근거 연결 AI 분석 및 대시보드 시각화**: 뉴스 근거 번호(`news_ids`)와 재무 사실 식별자(`fact_id`)에 기반한 AI 설명 생성·검증, 좌우 분할 대시보드(지표 카드·주가/거래량 차트·실적/재무 표 및 차트·관련 종목 비교·인사이트·뉴스) 표시
6. **엑셀(XLSX) 다운로드**: 화면에 표시된 선택 종목의 동일 결과(`DashboardResult`)를 바탕으로 셀 참조 네이티브 차트가 포함된 XLSX 파일 생성 및 다운로드

### 1.2 서비스 대상 사용자 및 검색 목적 정의 (`D10`)
- **대상 사용자**:
  - 관심 있는 산업·기술 테마(예: 반도체, 2차전지, 로봇 등)는 있으나, 어떤 국내 상장 기업이 연관되어 있는지 일일이 찾고 종목코드·주가 지표·전자공시 재무제표·최신 뉴스를 각각 다른 사이트에서 모아 비교하기 어려운 사용자
  - 단순 수치 나열이나 자극적인 매매 추천 대신, **수치의 출처·기준 기간·공시 근거가 명확히 연결된 요약 정보**를 원하는 정보 탐색자 및 학습자
- **핵심 가치**:
  1. **탐색(Exploration)**: 테마 키워드에서 검증된 국내 상장 종목 후보를 빠르게 발굴하고 원하는 종목을 직접 선택·전환하며 탐색
  2. **근거 확인(Evidence Verification)**: 모든 금융 수치의 출처·기준 시각·실적 기간·산식을 투명하게 공개하고, AI 설명 문장마다 실제 뉴스 번호 및 재무 사실 ID를 연결하여 할루시네이션(임의 숫자 생성·근거 없는 단정)을 차단
  3. **시각 비교(Visual Comparison)**: 일별 가격·거래량 추이, 최근 연간/분기 실적 추이, 재무구조 및 관련 후보 종목 요약을 차트와 표로 직관적으로 비교
- **목적의 한계 명시**:
  - 본 서비스의 목적은 **정보 탐색과 기업·테마 이해의 개선**이며, 미래 주가 예측이나 **투자수익 보장, 매수·매도 추천을 목적으로 하지 않습니다.**

## 2. 사용자 시나리오 정의 (WBS `D11`)

### 시나리오 1: 테마 입력 및 후보 종목 탐색 (선택 대기 상태)
1. 사용자가 좌측 입력 영역에 관심 테마(예: `"반도체"`)를 입력합니다.
   - 공백 입력이나 120자 초과 입력은 외부 API를 호출하지 않고 즉시 입력 안내를 표시합니다.
2. 시스템이 AI에게 후보 3개를 요청하고 KRX 상장 목록과 대조합니다(미확인 종목 포함 시 1회 재제안).
3. 좌측 및 후보 영역에 3개 후보의 종목명·6자리 종목코드·시장(KOSPI/KOSDAQ)·상장 확인 상태·미확인 사유가 표시됩니다.
4. **최초 선택 전 상태**: 사용자가 아직 종목을 선택하지 않았을 때는 상세 금융·뉴스·AI 호출을 수행하지 않으며, 우측 패널에 **"분석할 종목을 선택해 주세요"** 안내를 표시하여 분석 완료 화면과 명확히 구분합니다.

### 시나리오 2: 분석 종목 선택 및 대시보드 결과 확인
1. 사용자가 상장 확인된 후보(예: 후보 1, 후보 2, 또는 후보 3)를 선택 위젯이나 우측 관련 종목 카드에서 선택합니다.
   - 상장 미확인 후보나 지원하지 않는 시장(KONEX 등) 후보는 선택할 수 없으며 사유를 안내합니다.
2. 후보를 다시 AI로 생성하지 않고, 선택된 종목코드(`selected_code`)에 대해 금융 지표·가격 이력·재무제표·뉴스·AI 설명을 수집합니다.
3. 우측 대시보드에 선택 종목의 상단 4대 지표(주가·PER·PBR·ROE), 보조 지표(EPS·BPS), 주가·거래량 차트, 기업 실적·재무 요약 및 상세 표/차트, 관련 종목 요약, AI 핵심 인사이트, 관련 뉴스 원문 링크가 표시됩니다.

### 시나리오 3: 종목 변경(전환) 및 명시적 재조회
1. 사용자가 후보 A를 보던 중 후보 B를 선택합니다.
2. 전환 즉시 이전 종목(A)의 상세 분석 결과·차트·AI 설명·오류 메시지·엑셀 다운로드 바이트를 무효화하고 후보 B를 기준으로 조회합니다.
3. 만약 후보 B 조회 중 필수 금융 조회 실패 등 오류가 발생하더라도, 후보 B 제목 아래에 이전 종목(A)의 차트나 설명, 엑셀 파일이 남아 오인되는 일이 없도록 철저히 초기화합니다.
4. 단순 화면 재실행(rerun, 펼침 영역 조작 등)은 외부 API를 재호출하지 않고 세션 결과를 유지하며, 사용자가 명시적 **재조회**를 실행할 때만 해당 종목의 데이터를 갱신합니다.

### 시나리오 4: 일부 자료 누락 및 부분 실패 대응
1. **지표 일부 누락**: 주가는 있으나 PER·PBR·ROE 등이 없는 경우, 해당 카드는 단위 없는 `"정보 없음"`으로 표시하고 누락 경고를 안내하되 확보된 주가와 다른 지표는 정상 표시합니다. (단, 주가와 PER가 모두 없거나 종목 식별에 실패하면 필수 조회 실패로 중단합니다.)
2. **DART 재무 미공시/미설정**: DART API 키 미설정이나 해당 기간 공시 없음(`013`) 발생 시, 재무 영역에만 `"공시된 재무 자료 없음"` 또는 설정 안내를 표시하고 주가·차트·뉴스·기본 AI 설명은 그대로 보존합니다.
3. **뉴스 0건 또는 요청 실패**: 뉴스 검색 결과가 0건(`empty`)이거나 요청 실패(`failed`)인 경우 두 상태를 구분해 안내하고, 뉴스 기반 동향·기회·위험 인사이트를 임의로 생성하지 않습니다.
4. **AI 설명 생성/검증 실패**: AI 응답이 한도 초과이거나 검증되지 않은 숫자·추천 표현을 포함해 거부된 경우, 이미 수집한 주가·지표·차트·재무·뉴스 원자료는 화면에 그대로 표시하고 전체 완료 배지만 숨깁니다.

### 시나리오 5: 편집 가능한 엑셀(XLSX) 저장
1. 선택 종목 분석 결과가 준비되면 대시보드 다운로드 영역에 파일명·종목명·종목코드·기준 기간·생성 시각 안내와 함께 **엑셀 다운로드 버튼**이 활성화됩니다.
2. 다운로드 클릭 시 외부 API를 다시 호출하지 않으며, 현재 화면에 표시된 `DashboardResult`와 동일한 원자료로 생성된 메모리 내 XLSX 파일을 즉시 내려받습니다.
3. 생성된 엑셀 파일에는 요약·지표·가격이력·손익·재무상태·현금흐름·뉴스·출처 시트와 함께 실제 데이터 셀 범위를 참조하는 네이티브 엑셀 차트가 포함되어, 사용자가 엑셀에서 셀 수치를 수정하면 차트가 즉시 갱신됩니다.

## 4. 데이터 요구사항 정의 (WBS `D13`, `D14`, `D15`)

### 4.1 주가·금융 지표·재무제표 수집 항목 및 누락·정밀도 규칙 (`D13`, `D15`)

모든 수집 데이터는 **조회 시각(`retrieved_at`)**, **가격 자료 기준 시각(`price_at`)**, **가격 거래일(`trade_date`)**, **실적 기준 종료일(`period_end`)**, **사업연도(`bsns_year`) 및 보고서 구분(`reprt_code`, `fs_div`)**을 서로 분리하여 보관합니다. 조회 시각을 가격 기준 시각이나 실적 기준일로 대체하지 않습니다.

|---|---|---|---|---|---|
| **종목 식별** | 종목코드 / 기업 고유번호 | KRX `Code` (6자리) / DART `corp_code` (8자리) | 문자열 | 상장 목록 확인 시점 | 선행 `0`을 보존하는 고정 길이 문자열(`"005930"`, `"00126380"`). 정수 변환 금지. |

| **밸류에이션** | 주가순자산비율 (`PBR`) | `priceToBook` 우선, 누락 시 동일 기준 `price / BPS` (`BPS > 0`) | `배` | 제공 기준 또는 BPS 기준 기간 명시 | `None`이면 `"정보 없음"`(0배 표시 금지). 음수·0 자본인 경우 임의 양수화 금지 및 해석 주의 표시. |
| **주당 지표** | 주당순이익 (`EPS`) | `trailingEps` 또는 TTM `DilutedEPS` / `BasicEPS` | `주당 원` | TTM 또는 최근 실적 종료일(`period_end`), 기본/희석 여부 | PER 유무와 무관하게 독립 `MetricValue`로 수집. `0`·음수(적자)·누락(`None`)을 엄격히 구분. |

| **재무상태표 (BS)** | 자산총계, 부채총계, 자본총계(전체/지배) | OpenDART `BS` (`ifrs-full_Assets`, `ifrs-full_Liabilities`, `ifrs-full_Equity` 등) | 원자료 `원` (화면 표시 `억원`) | 기말 시점 기준일, `bsns_year`, `reprt_code`, `CFS`/`OFS`, `rcept_no` | 기말 잔액이므로 분기 누적 차감을 절대 수행하지 않음. 누락을 `0`으로 채우지 않음. |

| **재무 비율** | 부채비율 | `부채총계 / 자본총계 × 100` (동일 기말·동일 `CFS`/`OFS`) | `%` | 해당 재무상태표 기말 기준일 및 `CFS`/`OFS` | 자본총계가 `0` 이하(자본잠식)이거나 누락 시 정상 비율로 계산하지 않고 `"자본잠식 / 계산 불가"` 상태로 분리. |

### 5.1 아키텍처 및 데이터 흐름 핵심 원칙 (`D122`)
- **사용자 흐름**: `테마 입력` → `AI 후보 3개 제안 + KRX 상장 대조 (discover_theme_candidates)` → `선택 대기 화면` → `사용자 종목 선택 (select_candidate)` → `선택 종목 통합 분석 (analyze_selected_stock: 기본지표·OHLCV·OpenDART·뉴스·AI)` → `대시보드 표시 및 동일 결과 엑셀 다운로드 (build_workbook_bytes)`.
- **AI 근거 및 검증 분리**: 숫자는 수집 원자료에서 카드·표·차트로 직접 표시하고, AI는 뉴스 근거 번호(`news_ids`)와 재무 사실 식별자(`fact_id`)만 인용하여 문장을 생성합니다. 문장 내 미검증 숫자·URL·투자 권유(`매수`·`매도`·`목표주가`) 및 부호(`흑자`/`적자`/`자본잠식`)·범위(`CFS`/`OFS`) 불일치는 로컬 검증기에서 차단합니다.
- **표시·내보내기 계층의 순수성**: 차트 모듈(`charts.py`)과 엑셀 모듈(`excel.py`)은 내부에서 외부 API를 호출하지 않으며, 파이프라인이 반환한 단일 `DashboardResult`만 사용합니다.

### 5.2 예상 개념 이미지와 실제 구현 화면의 구분 (`D123`)
- 기획 단계의 개념 이미지는 레이아웃 설명용 시안이며, 실제 구현 화면은 **2026-10-20 실제 API 응답 수치**(`삼성전자 005930`, `SK하이닉스 000660`, `LG화학 051910`)와 단위(`원`, `주당 원`, `배`, `%`, `억원`, `주`), 조회 시각 및 가격/공시 기준일을 명확히 분리해 표시합니다.
