# 직접 실행해서 확인할 항목

확인 기준: **2026-10-20**. 로컬 자동 검사 **133개**를 모두 통과했으며, 실제 외부 API(`KRX`, `yfinance`, `OpenDART`, `NAVER`, `Groq`)를 연결한 선택형 대시보드·재무·엑셀 화면 자동 검사도 별도로 수행했다. [실제_API_검수결과.md](실제_API_검수결과.md)와 [기획서_구현결과_최종보고서_정리.md](../../기획서_구현결과_최종보고서_정리.md)를 참조한다.
기획 단계의 개념 이미지는 예상 시안으로 구분하며, 실제 화면 확인 및 캡처 시에는 **캡처 날짜·선택 종목명/코드·표시 단위(`원`, `주당 원`, `배`, `%`, `억원`, `주`)·조회 시각**을 함께 기록한다.

## 1. 처음 실행

- [ ] README의 명령으로 프로그램이 열리는지 확인한다.
- [ ] 입력창이 보이고 첫 입력 전에는 결과가 표시되지 않는지 확인한다.
- [ ] AI 키, 사용 가능한 모델 이름, NAVER API HUB 인증값을 확인한다. 키 값은 실행 기록이나 화면 캡처에 넣지 않는다.

## 2. 정상 입력

“반도체”, “2차전지”, “제약바이오” 등의 테마를 하나씩 입력한다. 후보는 AI 응답에 따라 달라질 수 있다.

- [ ] 관련 종목 후보 세 개가 표시되는지 확인한다.
- [ ] 첫 번째 후보가 대표 종목으로 표시되는지 확인한다.
- [ ] 종목명·코드·시장이 실제 상장 정보와 일치하는지 확인한다.
- [ ] 주가와 PER가 금융 출처의 값과 맞는지 확인한다. 표시 시 반올림과 조회 시점 차이를 고려한다.
- [ ] 숫자가 없으면 단위 없이 “정보 없음”으로 표시되는지 확인한다.
- [ ] 자료 출처, 조회 시각, 가격 자료 시각 또는 시각 미확인 안내가 보이는지 확인한다.
- [ ] 뉴스 제목과 발행 시각이 보이며 링크가 실제 기사를 여는지 확인한다.
- [ ] AI 설명의 뉴스 번호가 화면의 해당 뉴스 번호와 연결되는지 확인한다.
- [ ] AI 설명이 제목에서 알 수 없는 사실이나 기사 본문 내용을 덧붙이지 않았는지 직접 읽는다.
- [ ] 테마 동향, 후보, 대표 종목, 핵심 인사이트가 구분되어 보이는지 확인한다.

## 3. 오류·누락 상황

일부 상황은 실제 서비스에서 쉽게 발생하지 않는다. 그런 상황은 아래 로컬 검사로 우선 확인하고, 직접 재현하지 못한 항목은 공백으로 남긴다.

- [ ] 빈 입력·공백 입력을 처리하는지 확인한다. 화면에서 제출되지 않으면 로컬 입력 검사로 확인한다.
- [ ] AI 후보가 비어 있거나 중복되면 다시 입력하라는 안내가 있는지 확인한다.
- [ ] 첫 번째 후보가 미확인이면 다른 후보로 바꾸지 않고 분석을 중단하는지 확인한다.
- [ ] KOSDAQ 종목에 KQ, KOSPI 종목에 KS 조회 코드를 사용하는지 확인한다.
- [ ] 주가·PER가 모두 없으면 분석을 중단하는지 확인한다.
- [ ] PER만 없으면 누락을 표시하고 있는 자료를 보존하는지 확인한다.
- [ ] 뉴스 0건과 뉴스 요청 실패가 다른 안내로 표시되는지 확인한다.
- [ ] 뉴스가 없을 때 뉴스 기반 동향·인사이트를 생성하지 않는지 확인한다.
- [ ] 두 번째 AI 호출이 실패하면 조회 자료는 보이고 설명 완료로 표시되지 않는지 확인한다.
- [ ] 새로운 입력이 실패했을 때 이전 결과가 새 결과인 것처럼 남지 않는지 확인한다.
- [ ] “현재 결과 지우기”를 눌렀을 때 화면 결과가 지워지는지 확인한다.
- [ ] 누락·실패 상황에서 전체 분석 완료 메시지가 나오지 않는지 확인한다.
