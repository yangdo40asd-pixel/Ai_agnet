관심 있는 주식 테마를 입력하면 관련 회사 후보를 찾고, 대표 회사의 주가·PER와 뉴스 제목을 모아 한 화면에서 이해할 수 있도록 설명한다. 사용자가 숫자와 설명의 출처를 확인할 수 있어야 한다.

- [x] 최신 지시에 따라 코드 테스트는 에이전트가 수행하고, 브라우저를 통한 실제 시연은 사용자가 한다는 기준을 기록했다.

- [x] 실제 API 연동 검사도 별도로 수행했다. 결과와 제한은 실제_API_검수결과.md 및 검수자료/실제_API_검수.json에 기록한다.

**[x]는 해당 항목의 작업이 끝났다는 뜻이다.** 코드 작성, 로컬 자동 검사, 실제 외부 연동 확인을 구분해서 적는다. 모의 응답 검사만으로 실제 API가 작동한다고 판단하지 않는다. 담당자 A/B 구분은 넣지 않는다.
