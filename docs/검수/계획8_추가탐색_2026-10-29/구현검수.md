# 계획8 세 번째 실행 — 추가 종목 탐색과 복수 기업 참조

날짜: 2026-10-29 / 브랜치 woong. 사용자 ‘진행’ 지시에 따라 E02/C02의 추가 탐색과 집합 참조, 지원 범위의 연간 다기업 비교를 연결했다. UI 전면 재설계·사업 연관 근거 수집·전체 여정 완료 보고가 아니다.

## 구현된 동작

1. “관련주 더 보여줘/관련 종목 더 알려줘/다른 후보도 있어?”를 현재 테마의 추가 탐색으로 처리한다. 분류 모델이 임의의 종목 코드를 만들던 경로를 거치지 않는다.
2. 앞서 소개한 이름을 생성 요청에서 제외하고, 상장 목록으로 다시 확인한 새 후보만 누적한다. 생성·스키마 계약은 한 번에 1~3개다. 반드시 세 개를 채울 필요가 없고 전체 후보는 세 개에 묶이지 않는다. 과거 호출 호환성을 위해 validate_candidate_names의 기본3개 인수는 남겼지만 실제 생성 경로는 1~3개를 명시한다.
3. 추가 탐색은 현재 선택 기업·분석 결과·보관 캔버스·대화를 초기화하지 않는다. 새 후보가 없거나 요청이 실패해도 기존 탐색 결과를 유지한다.
4. `CandidateDiscoveryResult.batch_codes`와 `latest_candidates`로 최근 소개한 집합을 구분한다. “그 기업들”은 최근 집합/직전 비교를, “지금까지 소개한 기업들/전체 후보”는 누적 집합을 참조한다. 세 기업 중 “그 두 기업”처럼 모호하면 임의로 둘을 고르지 않고 확인한다.
5. 명시적인 다른 기업 이름이 있으면 그 대상을 우선한다. 다른 테마를 명시한 추가 탐색은 기존 테마로 잘못 이어 붙이지 않는다. 단순 “더 설명해줘”, 다른 회사의 뉴스 질문, 탐색 거부 표현을 추가 후보 요청으로 확대하지 않는다.
6. 기존 동일 기준의 연간 비교를 2~6개 기업으로 확장했다. 모든 기업의 공통 전기·당기/연결·별도/원화/지원 항목을 확인한다. 어느 한 기업의 자료가 실패하거나 기준이 맞지 않으면 임의로 나머지 기업만 성공 비교로 표시하지 않는다.
7. 세 기업 이상에서는 매출 증감률·영업이익률과 각 기업의 손익 상태를 설명한다. 적자·흑자 전환을 일반 성장률로 순위 매기지 않고, 투자 추천 순위도 생성하지 않는다.

## 코드 책임

- `src/agents/discovery_context.py`: 추가 탐색과 집합 지시어 해석. 생성·API·화면과 분리했다.
- `src/agents/request.py`: 기존 종목·관계 검증보다 앞서 알려진 추가 탐색과 집합 참조를 처리하되 명시된 기업을 무시하지 않는다.
- `src/models.py`: 누적 후보와 마지막 소개 집합을 구분한다. 기존 생성자 인수는 유지했다.
- `src/agents/report.py`, `src/agents/output_contract.py`, `src/data/stock.py`: 1~3개 후보·제외 이름·유일성·공식 상장 이름 계약을 연결한다.
- `src/pipeline.py`: 상장 대조와 한 번의 기존 재제안을 재사용하며 새 후보를 누적한다. 테마 불일치·반복 기업·미확인 후보를 새 성공으로 처리하지 않는다.
- `src/ui/state.py`: 추가 저장 함수가 선택·분석·캔버스를 초기화하지 않도록 책임을 분리했다.
- `src/ui/app.py`: expand 처리 경로와 2~6개 비교를 연결한다. 선택 버튼은 최근 추가 집합을 표시하고 전체 후보는 기존 상세 선택 경로에 남는다.
- `src/data/company_comparison.py`: 모든 기업의 공통 기간과 공통 항목 교집합을 검사한다.
- `src/comparison_flow.py`: 2~6개로 수집을 제한하고 중복·미확인 대상을 호출 전에 거절한다. 기존 PER·분기 등 미지원 비교 경계를 유지한다.
- `src/agents/company_comparison.py`: 두 기업의 기존 응답을 보존하고 다기업 설명을 추가했다. 출처·결과 ID 조립은 공통 함수로 통합해 두 경로의 중복을 줄였다.

## 자동 검수

- 전체 **763개 / 55.257초 통과**. 기존746개 + 신규17개다.
- 이후 출처 조립의 공통화와 다기업 문장·짧은 요약 표시를 정리하고, 기존 비교22개(3.699초)와 신규17개(2.473초)를 다시 통과했다. 문서·해시 외 다른 변경은 없다. 전체763개가 최종 표현 변경 뒤 다시 실행됐다고 기재하지 않는다.
- 신규17개는 추가 탐색의 모델 분류 우회, 새 테마, 뉴스/거부 표현, 최근·전체 후보 집합, 모호한 두 기업, 명시 기업 우선, 1~3개 스키마와 중복 거절, 후보 누적·실패 보존·선택 보존, 다기업 공통 기준·결과 ID·기업 수 상한·짧은 표시, 실제 화면 처리 코드(AppTest)의 추가 탐색과 세 기업 비교를 검수했다.
- 자동 검사 중 외부 응답은 대체했다. AppTest는 기존 브라우저 세션을 읽지 않는 독립 소프트웨어 테스트이며 실제 화면 육안 검수가 아니다.
