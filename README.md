## 실행하기

기존 환경에서는 프로젝트 루트의 start.bat을 사용한다. 직접 실행하려면 다음과 같다.

```powershell
Set-Location D:\ai_agent
.\venv\Scripts\python.exe -m streamlit run .\src\ui\app.py
```

새 환경의 기본 실행 패키지는 requirements-core.txt 기준이다. 챗봇용 추가 패키지는 없으며 기존 Groq 설정을 사용한다.

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements-core.txt
```

기존 .env를 .env.example로 덮어쓰지 않는다. 현재 설정은 src/config.py가 읽으며 실제 키는 코드·화면·문서·로그에 기록하지 않는다.

| 설정 | 용도 |
|---|---|
| GROQ_API_KEY | Groq의 AI 호출 인증 |
| GROQ_MODEL | 기본 openai/gpt-oss-20b. 모델 이용 권한/한도는 계정과 제공 시점에 따름 |
| NAVER_CLIENT_ID / NAVER_CLIENT_SECRET | 현재 NAVER API HUB 뉴스 인증. Developers 검색 API 인증과 혼동하지 않음 |
| DART_API_KEY | OpenDART 기업 재무 조회. 미설정 때 재무 영역은 수집하지 않음 |
| NEWS_SORT | date(기본) 또는 sim |
| REQUEST_TIMEOUT | 뉴스·AI·DART의 명시적 요청 제한 설정. KRX/yfinance 모든 내부 요청에 적용되는 전역 제한은 아님 |

## 현재 처리 순서

1. 대화 입력은 빈 값·1,200자 제한을 검사하고 테마 탐색/종목 선택/후속 질문/재조회 의도를 구분한다. 후보 탐색용 테마는 별도로 120자 이내로 제한한다.
2. Groq에 후보3개를 요청하고 응답 형식을 검사한다.
3. FinanceDataReader의 KRX 목록으로 이름·코드·시장을 대조한다. 필요하면1회 재제안/재대조한다.
4. **선택 대기**를 표시한다. 사용자가 selectable 후보를 고른 뒤 상세 수집을 시작한다.
5. 선택 코드가 현재 후보에 속하는지 검증하고 주가/PER/EPS/BPS/PBR을 조회한다. 누락은0이 아닌 정보 없음이다.
6. 선택 종목 일별 OHLCV를 수집한다. 미선택 후보는 현재 기본 경로에서 시세를 추가 조회하지 않는다.
7. DART가 설정됐으면 최근3개 연간 재무·주요 지표를 수집하고 단위·계정·기간·비율을 정리한다.
8. 선택 종목과 테마로 뉴스 제목 최대3건·발행시각·원문/제공 링크를 수집한다. 본문은 수집하지 않는다.
9. 금융/뉴스 기반 기본 설명과 재무 사실id 기반 설명을 생성한다. 형식·회사명·수치·근거·부호/범위 등을 로컬 검사한다.
10. 지표6개·가격/거래량·연간 재무표/차트·뉴스를 우측에, AI 분석 리포트를 좌측 채팅에 표시하고 같은 결과 객체로 XLSX를 생성한다.
11. 후속 질문은 현재 선택 종목의 자료와 최근 대화 문맥으로 답한다. 일반 질문으로 금융·뉴스 API를 다시 호출하지 않는다. 새 테마는 후보/선택 자료를 갱신하고 대화는 보존하며, 새 대화 시작은 전체 상태를 초기화한다.

뉴스/AI/DART 등의 일부 실패는 해당 상태로 보관한다. 기본 필수 종목 식별/금융 실패는 중단하며, AI 설명 실패 때 이미 받은 자료를 보존한다. **현재 complete 판정은 기본 금융·뉴스·기본AI 중심**이므로 전체 확장 기능의 검증 완료나 WBS100%를 뜻하지 않는다.

PER는 제공 trailingPE를 우선하고, 없으면 조건에 맞는 원화 TTM 희석EPS로 계산해 근거/종료일을 표시한다. 공식 ROE 제공값과 자체 계산을 구분한다. 자체 ROE에는 평균자본 우선과 기초값 없을 때 기말자본 대체 경로가 있으므로 모든 ROE를 같은 산식이라 설명하지 않는다.

## 화면과 파일

- 좌측: 사용자/AI 대화, 종합 분석 리포트·근거, 후보 표·종목 선택·가격 범위·재조회.
- 우측: 주가/PER/PBR/ROE, 보조EPS/BPS, 가격/거래량, 연간 손익/재무상태/현금흐름/비율, 뉴스·엑셀 다운로드.
- 대화는 현재 세션에서 최근 40개 메시지를 유지하고 AI에는 최근 12개 문맥을 전달한다. 서버 재시작·새 세션을 넘는 영구 저장은 지원하지 않는다.
- 관련 후보: 선택 버튼과 요약 표시 구조가 있다. 현재 **선택 종목 이력만 재사용**하고 미선택 후보는 조회 대기 안내다.
- 엑셀: 요약·핵심지표·일별시세·손익계산서·재무상태표·현금흐름표·관련뉴스·출처및산식의8시트. 네이티브 차트는 실제 데이터 셀 범위를 참조한다.
- 종목/가격 범위/명시 재조회 변경 시 결과와 파일을 무효화하고 같은 결과의 rerun/다운로드는 세션 자료를 재사용한다. 이는 제공자별 네트워크 캐시 구현과 다른 기능이다.

## 패키지

활성 core 목록은 streamlit, yfinance, finance-datareader, requests, pandas, plotly, XlsxWriter, python-dotenv, langchain-groq다. 상세 버전은 구현 결과 정리 문서에 **현재 설치값**으로 기록한다. 고정 버전/재현 환경을 보장하는 lock 파일은 아니다.

openpyxl은 src/export/excel.py의 대조 함수와 자동/실제 검수에서 사용한다. 현재 requirements-core.txt에는 포함되지 않으므로 새 환경에서 그 검수를 수행할 때 별도로 필요하다.

```powershell
.\venv\Scripts\python.exe -m pip install openpyxl
```

과거 requirements.txt는 실험/후보 목록이다. 설치돼 있거나 목록에 있다는 이유만으로 사용 API/구현 완료로 세지 않는다. Selenium·crewai·reportlab 등은 현재 핵심 실행 기능의 근거가 아니다.

## 자동 검사와 실제 API 기록

2026-10-20 챗봇 추가 후 전체 자동 검사 154개가 17.878초에 통과했다. 외부 요청을 대체한 사용자 흐름·오류 처리 검사이며 실제 화면 육안 확인과는 구분한다.

```powershell
Set-Location D:\ai_agent
.\venv\Scripts\python.exe -m unittest discover -s tests -q
```

run_test.bat도 같은 검사 탐색 명령을 사용한다. 배치 안내 문구의 과거 개수와 별개로 실제 탐색 대상은 현재 154개다.

전체 금융·뉴스 연동의 기존 기록은 검수자료/실제_API_검수.json에 있다. 챗봇 추가에서는 실제 AI API로 일반 용어 질문·선택 종목 PER 설명·PBR 누락 안내를 확인했다. 챗봇 검사에는 가상 종목 자료를 사용했으며 금융·뉴스 API 전체를 재검수한 것은 아니다. 기록: [챗봇 API 검수](<D:/ai_agent/검수자료/챗봇_API_검수.json>).

실제 검수를 다시 실행하려면 다음 명령을 명시적으로 사용한다. 외부 API 사용량이 발생하고 기본 테마 간격은 현재 스크립트 기준35초이며 JSON 파일은 갱신된다.

```powershell
.\venv\Scripts\python.exe scripts/verify_live.py --live
```

기본 입력은 반도체·2차전지·로봇이다. 첫 테마는 두 번째 후보 전환도 검사한다. 종료0은 제한된 검사 성공,2는 음수PER 등 안내 포함 성공,1은 실패다. 성공 기록은 해당 시점/입력의 확인이지 모든 회사/매일의 성공 보장이 아니다.

## 남은 확인과 미연결 범위

- 실제 분기/반기 수집과 사업연도/보고서 옵션의 전체 연결. 분기 변환/차트 함수 존재와 실제 분기 화면 완성은 다르다.
- 미선택 후보의 동시 가격·등락·미니 차트 조회.
- 공식 ROE API의 연결/별도 기준과 재무표 범위 구분, 평균/기말자본 계산 대체 설명.
- 전체 완료 메시지와 확장 영역 상태의 일치, 실제 PBR/BPS 제공값 사례, 모든 엑셀 값/기간/출처 대조.
- 장시간 반복/동시 요청·장애 복구·제공자 이용조건 확인.
- 사용자 브라우저 가독성·Excel 열기/셀 편집·화면 캡처·최종 제출본/시연.

주가는 지연될 수 있고, 상장 확인만으로 테마 연관성을 입증하지 않는다. 뉴스는 제목 기반이며 수치/id 검사만으로 AI 문장의 사실성을 완전히 보장하지 않는다. 도구 라이선스와 원천 데이터의 표시/다운로드 조건도 별도로 확인한다.

PDF 다운로드·회원·매매 주문·실시간 호가 스트리밍은 현재 구현 기능으로 적지 않는다. 이전 기본판의 ‘그래프/재무/PBR/ROE 전체 미구현’ 설명 대신 위 실제 연결/잔여 범위를 기준으로 본다.
