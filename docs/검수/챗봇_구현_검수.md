# 대화형 챗봇 구현·검수 — 2026-10-20

사용자가 승인한 **기본 테마 분석 서비스 → 대화형 챗봇** 9개 업무를 구현했다. 이번 변경은 프로그램 기능 추가이며 WBS 엑셀·간트·Week1~2 완료 기록은 수정하지 않았다.

## 구현 범위

- [x] 연속 질문과 종목 분석을 포함한 챗봇 이용 흐름: 테마 검색 → 후보 선택 → 리포트 → 후속 질문을 연결.
- [x] 사용자·AI 메시지 및 현재 테마·종목 대화 상태: 세션 내 최근 40개 메시지 보관. 모델에는 최근 12개 문맥과 현재 분석 자료만 전달.
- [x] 일반 질문·테마 분석·종목 변경의 의도 구분: 명확한 요청은 직접 분기, 나머지는 AI 분류 및 허용 동작/후보 코드 검증.
- [x] 이전 대화의 테마·선택 종목을 반영한 후속 질문: 앞선 리포트 설명도 문맥으로 전달. 종목 변경 이후 수치 근거는 새 결과에서 구성.
- [x] 챗봇 요청과 기존 종목·금융·뉴스 조회 연결: 기존 파이프라인 재사용. 후속 설명은 기존 결과 사용, 명시적 재조회는 갱신.
- [x] 수집 자료와 대화 문맥을 결합한 근거 기반 답변: 수치·링크를 모델 본문에서 임의 생성하지 않도록 검사하고 검증된 원자료를 별도 근거로 표시. 근거 ID·중복·형식·길이 검사, 실패 시 1회만 재생성.
- [x] 사용자·AI 메시지를 누적하는 대화 화면.
- [x] AI 종합 분석 리포트를 챗봇 대화에 표시. 당시 종목·조회 시각·뉴스·재무 근거도 보존.
- [x] 새 대화 시작: 대화·테마·후보·선택·결과·엑셀 캐시 초기화. 새 테마 검색은 대화 기록을 보존.

체크는 코드와 아래 제한된 검사를 통과했다는 뜻이다. 모든 표현·종목·장애 상황 및 브라우저 가독성까지 확인했다는 뜻은 아니다.

## 주요 변경 파일

- `src/agents/chat.py`: 의도 분류, 대화 문맥 구성, 근거 자료 구성, 후속 답변 검증.
- `src/agents/report.py`: 기존 AI 호출에 대화 전용 응답 스키마 추가.
- `src/ui/app.py`: 대화 처리, 후보/재조회 연결, 채팅 리포트와 근거 표시.
- `src/ui/state.py`: 대화 기록과 분석 결과 상태를 구분하여 초기화.
- `src/ui/dashboard.py`: 주 화면에서 리포트를 채팅으로 옮기고 지표·차트·뉴스·엑셀은 상세 화면에 유지.
- `tests/test_chat.py`: 신규 자동 검사 21개.

## 검수 결과

- 전체 자동 검사: **154개 통과 / 17.878초**. 외부 네트워크를 대체한 기존 133개와 챗봇 21개.
- 신규 검사는 후속 질문의 결과/엑셀 보존, 후보 재탐색 없는 종목 변경, 현재 종목의 근거 사용, 새 테마 전환, 새 대화 초기화, 명시 재조회, 재실행 중복 방지, 잘못된 근거·수치·응답 차단, 1회 재생성 한도를 포함한다.
- 실제 AI API: 일반 PER 용어 설명, 선택 종목 PER 후속 설명, PBR 누락 안내의 의도 분류와 답변을 확인했다. **가상 종목 데이터**를 주입한 AI 연동 검사다.
- 초기 실제 응답에 숫자가 포함되어 차단되는 현상을 발견했다. 대화 전용 출력 스키마 및 검증 실패 시 1회 재생성을 추가한 뒤 세 사례가 통과했다.
- 실제 금융·뉴스 API 전체 흐름은 이번에 다시 실행하지 않았다.
- 브라우저·앱 서버는 시작하지 않았다. Streamlit AppTest로 화면 동작을 확인했다.

원시 기록: `D:/ai_agent/검수자료/챗봇_자동검사.txt`, `D:/ai_agent/검수자료/챗봇_API_검수.json`.

## 직접 확인할 순서

1. 기존 `start.bat`으로 실행한다.
2. `반도체 테마주 분석해줘` 입력 → 후보가 표시되면 한 종목을 선택한다.
3. 왼쪽 채팅 안의 분석 리포트와 오른쪽 지표·차트·뉴스를 확인한다.
4. `이 종목의 PER를 쉽게 설명해줘`, `그럼 어떤 점을 더 확인해야 해?`처럼 이어서 질문한다.
5. 다른 후보의 실제 이름으로 `○○로 바꿔줘` 입력 → 분석 대상과 후속 답변의 근거가 바뀌는지 확인한다.
6. `재조회해줘` 입력 → 현재 종목을 다시 조회한다.
7. 새 테마를 입력하면 대화는 남고 선택 자료가 초기화되는지, `새 대화 시작`으로 모두 지워지는지 확인한다.
