## 실제 자료에서 찾아 수정한 문제

1. 공식 원문에 XML 이스케이프가 되지 않은 `< 5% hydrogen`, `R&D`, `<보수지급금액 5억원 이상인 이사ㆍ감사의 개인별 보수현황>` 같은 문자 표기가 있어 원문 전체 파싱이 실패했다. 숫자 비교 기호·문자 앰퍼샌드·속성이 될 수 없는 공백 포함 한글 표제만 이스케이프해 동일한 표시 내용을 유지한다. 잘못된 태그를 임의 복구하거나 DOCTYPE/ENTITY를 허용하지 않는다. 기존 일반 공시 파서의 검증 규칙은 변경하지 않았다.
2. 상장 약칭HPSP와 공시 법인명에이치피에스피가 달랐다. 회사별 별칭 예외 대신 기존 종목→고유번호 매핑과 표지AREGCIK를 대조했다. 다른 고유번호의 문서는 거절하고, 고유번호가 없는 표지는 기존 정확한 이름 대조를 사용한다.
3. 원문 API는 인증/한도 오류를ZIP 대신XML로 반환할 수 있다. auth_error/rate_limit을 형식 오류로 숨기지 않고 해당 배치의 남은 외부 조회를 중지한다. 정상 캐시 자료는 보존한다.
4. 최신 보고서를 추출하지 못하고 이전 문서를 사용하면 ok_earlier_report를 캐시 재사용 시에도 유지한다. 보고기간/접수일/조회일을 구분하고 ‘최신 유효 공시’라고 추정하지 않는다.
