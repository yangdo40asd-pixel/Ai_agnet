# 계획8 두 번째 실행 — ‘왜?’의 원인 자료 연결과 답변 표현 개선

작성일: 2026-10-28. 브랜치 woong. 계획8 A02-I3 및 첫 실행에서 남긴 원인 설명 문제를 보완했다.

## 실제 원인

삼성SDI의 매출원가·판관비 자료가 없었던 것이 아니다. 이미 `fnlttSinglAcntAll`에서 전체 손익계산서를 수집했으며 2024·2025년 자료에는 기타영업수익도 있었다. 기존 비용 계산은 매출−매출원가−판관비=영업이익인 경우만 허용해 해당 회사의 정상 비용 근거를 제외했다.

2024년 차이는 기타영업수익 89,856,873,442원, 2025년 차이는 기타영업수익 275,152,734,663원과 정확히 일치했다. 이 값은 남는 차이를 역산해서 만든 것이 아니라 기존 공시 API의 명시적인 계정에서 확인했다. 공식 공시 문서 원문과의 별도 육안 대조까지 완료한 것은 아니다.

## 구현

- `src/data/cost_structure.py`: 동일 회사·기간·연결/별도·원화 기준으로 매출−원가−판관비+확인된 기타영업수익−확인된 기타영업비용=영업이익을 정확히 대조한다. 기타수익·금융비용 같은 비영업 계정을 균형 맞추기용으로 사용하지 않는다. 계정 충돌·누락 값이 있거나 식이 맞지 않으면 비용 근거를 만들지 않는다.
- 추가 계정이 원문에 없으면 독립 Fact를 생성하지 않으며, 기본 3항 식이 그대로 맞는 기존 사례도 보존한다. 실제 존재한 추가 계정은 입력 근거 ID와 존재 여부를 함께 남긴다.
- `src/agents/financial_numbers.py`: 부호 있는 이익률과 손익의 정확한 비교 문법을 보강하고, 흑자/적자 전환도 검증기와 같은 포맷의 예시 문장으로 제공한다. 잘못된 값·부호·방향·기간은 계속 거절한다.
- `src/agents/answer_quality.py`: 동일 비교 기준일 때 항목별 검증 문장을 제공한다. 한 항목이 적자로 전환됐다는 이유만으로 나머지 비교의 예시까지 사라지지 않게 했다. 복수 기준 혼재 시 강제 통합하지 않는다.
- `src/agents/chat.py`: 검증된 비교 예시로 필요한 값과 의미를 설명하도록 연결했다. 직접 쓰기 어려운 비교만 기존 자리표시자로 보존해 모든 답변을 화살표 수치 나열로 만들지 않는다.
- `tests/test_plan8_cost_bridge.py`, `tests/fixtures/plan8_sdi_cost_statements.json`: 실제 정규화 자료 및 합성 반례로 손익 항등식·추가 계정·부호와 예시 계약을 확인한다.

## 검증

- 기존737개 + 신규9개 = **746개 통과 / 53.005초**. 신규 계정이 없는 기존 비용 검사10개도 별도 통과했다.
- 신규9개는 기타영업수익/비용의 방향, 비영업 항목의 대체 금지, 불일치/결측/다른 통화·기준 거절, 없는 계정의 Fact 생성 금지, 실제 삼성SDI 비용 근거, 정확한 음수 이익률 문장, 틀린 값·부호·방향 거절, 같은 기준의 항목별 예시를 검사한다.
- 보관된 실제 삼성SDI 자료를 사용해 **새 로컬 생성과 근거 심사**로 종합→원인→두 문장 요약을 확인했다. 외부 금융 재수집0회, local HTTP6회 모두200, 각 문항 첫 생성+첫 의미 심사, 재작성0회, 제한 답변0회였다.
- 시간: 종합16.651초 / 원인14.454초 / 요약10.383초. 자료 수집과 화면 렌더링 시간은 포함되지 않는다. 과거81.5초와 직접 성능 개선 비율을 계산하지 않는다.
- 실제 UI를 열거나 브라우저 세션을 읽지 않았다. 이번 함수 기반 확인을 육안 검수로 세지 않는다.

## 실제 답변 표본

아래 수치는 보관된 API 표본의 기간을 설명하는 것이며 최신 시세가 아니다.

**사용자: 왜 그런 거야?**

삼성SDI의 영업이익률이 하락한 주요 원인은 매출원가율과 판매관리비율이 동시에 상승하며 수익 구조가 악화되었기 때문입니다. 2024년 대비 2025년 매출원가율은 81.36%에서 88.98%로 7.63%p 상승했고, 판매관리비율 또한 17.00%에서 26.07%로 9.08%p 상승했습니다. 이러한 비용 비중의 동반 상승으로 인해 영업이익률은 2.19%에서 -12.98%로 15.17%p 하락하며 적자 전환하였습니다.

## 품질의 경계

이번 답변은 이전처럼 실적만 반복하지 않고 비용 비중 변화로 설명한다. 하지만 ‘매출원가율/판관비율’의 쉬운 풀이와 기타영업수익이 일부 보완한 효과를 자연어로 충분히 설명하지는 않았다. 비용 비중이 왜 늘었는지(판가·수요·생산효율 등)의 구체적 사업 원인은 이 계산만으로 확정할 수 없다. 사업 자료가 필요하면 실제 수집 범위를 더 확인해야 한다.

원가율과 판관비율의 상승폭을 단순 합산해 이익률 하락폭과 같다고 단정해서는 안 된다. 기타영업수익/비용이 포함될 수 있으므로 이번 계산 근거에 해당 구성도 보존한다. 표시 반올림값의 단순 차이와 원값으로 계산한 %p의 차이도 허용된 표시 정밀도 안에서 설명한다.

이번3문항은 특정 실제 자료의 표본이다. 전체 기업·기준·누적/분기·긴 대화의 품질 완료가 아니다. A02-V1의 전체 수용 검수 및 A~F 여정은 미완료로 유지한다.
