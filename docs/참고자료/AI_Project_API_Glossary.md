# AI인사이트리포트 핵심 API 및 기술 도구 정리서

**작성일:** 2026. 09. 21  

---

본 문서는 'AI 테마주 인사이트 리포트' 시스템 구축을 위해 채택된 핵심 오픈 API 및 라이브러리의 개념과 실제 프로젝트 적용 목적, 대안 기술 대비 선택 이유를 정리한 기술 레퍼런스이다.

---

### 1. yfinance (야후 파이낸스 금융 데이터 API)
* **■ 개념 및 정의:**  
  야후 파이낸스(Yahoo Finance)의 금융 데이터를 파이썬 환경에서 간편하게 조회할 수 있도록 지원하는 오픈소스 라이브러리이다. 전 세계 주식, ETF, 지수 등의 실시간 시세와 기본 재무제표 데이터를 단 몇 줄의 코드로 호출할 수 있다.
* **■ 도입 및 선택 이유:**  
  금융 데이터 수집 도구로 여러 상용 유료 API가 존재하지만, yfinance는 100% 무료이며 별도의 복잡한 API 키 발급 없이 즉시 사용 가능하다는 결정적 장점이 있다. 종목코드(티커) 객체 하나로 현재 주가뿐만 아니라 PER 등의 가치평가 지표를 단일 호출로 빠르게 확보할 수 있어, 실시간 응답 속도가 중요한 AI 인사이트 리포트의 1차 가격 데이터 공급원으로 가장 적합하여 채택하였다.

### 2. FinanceDataReader (한국 주식 및 금융 데이터 수집기)
* **■ 개념 및 정의:**  
  한국거래소(KRX) 전체 상장 종목(KOSPI, KOSDAQ, KONEX) 및 글로벌 지수, 원자재 가격 등을 판다스(Pandas) 데이터프레임 형태로 손쉽게 수집해 주는 파이썬 오픈소스 금융 라이브러리이다.
* **■ 도입 및 선택 이유:**  
  yfinance는 해외 데이터베이스 기반이므로 '삼성전자'와 같은 한글 종목명을 직접 인식하지 못하며, 한국 주식 종목코드(예: 005930)를 반드시 알아야만 호출이 가능하다. FinanceDataReader는 KRX 전체 상장사 목록을 실시간으로 가져올 수 있어, AI가 추출한 한글 종목명을 정확한 6자리 종목코드로 변환해 주는 필수적인 '다리(매핑 파이프라인)' 역할을 수행하기 위해 도입하였다.

### 3. NAVER API HUB (네이버 검색 오픈 API)
* **■ 개념 및 정의:**  
  네이버 클라우드 플랫폼(NCP)의 API 게이트웨이를 통해 제공되는 공식 RESTful 검색 서비스로, 특정 키워드에 대한 최신 언론사 뉴스 기사 제목, 본문 요약(Snippet), 발행 일자, 원문 링크를 정형화된 JSON 포맷으로 제공한다.
* **■ 도입 및 선택 이유:**  
  웹 크롤링(BS)은 네이버 웹페이지의 HTML 구조가 변경되면 코드가 작동하지 않고 대량 요청 시 IP 차단 리스크가 매우 크다. 반면 NAVER API HUB는 공식 인증 키(Client ID/Secret)를 기반으로 일일 50,000회까지 안정적이고 합법적인 데이터 조회가 보장된다. 정제된 최신 증권 뉴스를 오차 없이 AI 분석의 근거 자료로 공급하기 위해 메인 수집 도구로 선택하였다.

### 4. Groq API (LPU 기반 초고속 LLM 추론 엔진)
* **■ 개념 및 정의:**  
  Groq 사의 독자적인 AI 가속 칩(LPU, Language Processing Unit)을 기반으로 오픈소스 거대언어모델(LLM)을 초고속으로 구동 및 서비스하는 클라우드 API이다.
* **■ 도입 및 선택 이유:**  
  사용자가 웹 화면에서 검색 버튼을 누른 후 리포트가 나오기까지의 대기 시간을 최소화하는 것이 사용자 경험(UX)의 핵심이다. 일반적인 클라우드 LLM(OpenAI 등)은 답변 생성에 5~10초 이상 소요되나, Groq은 1~2초 내에 고품질 텍스트 생성을 완료하는 압도적인 속도를 제공한다. 더불어 완전 무료 티어로 운영되어 프로젝트 개발 및 검증 비용을 전혀 발생시키지 않는다는 점에서 최우선 AI 두뇌로 선정하였다.

### 5. DART API & opendartreader (금융감독원 전자공시 API)
* **■ 개념 및 정의:**  
  대한민국 금융감독원 전자공시시스템(DART)에 공시된 국내 상장 기업의 공식 사업보고서, 감사보고서 및 재무제표(포괄손익계산서, 재무상태표 등) 원본 데이터를 열람할 수 있도록 지원하는 공공 오픈 API와 이를 파이썬으로 다루는 래퍼 도구이다.
* **■ 도입 및 선택 이유:**  
  yfinance 등 해외 데이터 소스는 국내 중소형 종목의 재무 지표가 누락되거나 최신 공시 반영이 지연되는 한계가 있다. DART API는 기업이 법적으로 제출한 공시 원본이므로 데이터의 법적 신뢰성과 정확도가 최고 수준이다. 향후 리포트에 실제 매출액, 영업이익, 부채비율 등 심층적인 정량 재무제표를 오차 없이 반영하기 위해 확장 도구로 채택하였다.

---

### 6. Selenium & webdriver-manager (웹 브라우저 자동화 도구)
* **■ 개념 및 정의:**  
  실제 크롬(Chrome) 등의 웹 브라우저를 파이썬 코드로 원격 제어하여 사람이 직접 클릭하고 스크롤하는 것과 동일하게 웹페이지와 상호작용할 수 있게 해주는 웹 자동화 오픈소스 도구이다. webdriver-manager는 브라우저 버전에 맞는 드라이버를 자동 설치/관리한다.
* **■ 도입 및 선택 이유:**  
  정적 파서(BS)나 일반 API는 자바스크립트(JS)로 화면이 동적 로딩되거나 로그인이 필수인 사이트의 데이터를 가져올 수 없다. 향후 증권사 HTS/MTS 웹 페이지의 동적 차트 데이터나 복잡한 금융 포털의 비공개 데이터 수집 등 고도화된 업무 자동화가 요구될 경우를 대비하여 선제적으로 인프라를 구축해 두었다.

---

### 7. Streamlit (파이썬 기반 대화형 웹 프레임워크)
* **■ 개념 및 정의:**  
  복잡한 HTML, CSS, JavaScript 및 별도 프론트엔드 프레임워크(React, Vue 등) 없이도 파이썬 스크립트만으로 대화형 대시보드와 AI 웹 서비스를 초고속으로 제작할 수 있는 데이터 과학 전문 웹 프레임워크이다.
* **■ 도입 및 선택 이유:**  
  2인 개발 팀 환경에서 프론트엔드 작업에 과도한 리소스를 뺏기지 않고, 데이터 파이프라인과 AI 에이전트 핵심 로직에 집중할 수 있도록 해준다. `st.text_input`, `st.spinner`, `st.markdown` 등 직관적인 위젯을 통해 사용자 친화적인 챗봇 형태의 단일 화면을 효율적으로 완성할 수 있어 최종 UI로 채택하였다.

---

### 8. LangChain (거대언어모델 에이전트 오케스트레이션 프레임워크)
* **■ 개념 및 정의:**  
  언어 모델(LLM)과 외부 데이터 소스(API, 데이터베이스, 검색엔진)를 유기적으로 결합하여 복잡한 다단계 추론 작업을 수행할 수 있도록 지원하는 AI 에이전트 개발 표준 프레임워크이다.
* **■ 도입 및 선택 이유:**  
  단순히 질문을 던지고 끝나는 구조가 아니라, [테마주 탐색 ➔ 코드 매핑 ➔ 시세/뉴스 수집 ➔ 팩트 주입 ➔ 리포트 작성]으로 이어지는 다단계 체인(Chain)과 엄격한 프롬프트 엔지니어링(이모티콘 배제, 증권사 리포트 규격 강제)을 체계적으로 제어하고 관리하기 위해 필수 뼈대로 도입하였다.
