# 실행02-B 자료 보강·질문 연결 검수 — 2026-10-29

## 판정과 다음 위치

**CARD-I3/I4/I5 구현·대표 정상/반례 검수 완료. 다음02-C / CARD-I6→I7.** 기존 기업/뉴스 답변과 금융 검증은 유지했다. 전체 실행02, 기업 카드 UI, 전체 테마의 품질 검수가 완료된 것은 아니다. 새 카드 자료형·생성 스키마·항목별 인용 심사·저장/표시는 아직 남았다.

사용자 지시대로 현재02-B부터 구현했다. 기존 미커밋 변경은 폐기하지 않았고 커밋·푸시, 실제.env·모델 가중치·WBS는 변경하지 않았다. 화면 서버만 같은 설정으로 재시작했으며 로컬 모델 서버1234는 유지했다.

## 구현한 연결

1. KIND의 정확한 회사명/코드 행에서 홈페이지 주소를 보존한다. 상세 사업 자료가 최신 추출 정책/1시간 기준으로 없거나 오래된 기업만 보강한다.
2. DART 정기보고서의 관련 사업 절을 우선한다. 결측이면 KIND 주소 또는 DART 기업개황의 hm_url/ir_url로 확인된 공식 페이지를 제한적으로 읽는다. 다른 회사의 등록 응답·외부 도메인·내부망 주소는 거절한다.
3. 공식 등록 호스트와 그 하위 제품 사이트만 허용한다. 모든 DNS 결과가 공인 주소여야 하며, 이동할 주소도 매번 확인한다. 최대3페이지/페이지별 크기/이동 횟수와 하위45초 예산을 두고 성공 자료만 캐시한다. 실패한 링크를 무제한 따라가지 않는다.
4. 사업·제품 제목별로 본문을 분리한다. 메뉴·숨김문·정책·사업연속성 안내와 무관한 소비재 광고를 제품 설명 근거에서 제외한다. 날짜가 없는 홈페이지에 발행일을 만들지 않고, 날짜만 있는 공시를 임의의 자정 시각으로 표시하지 않는다.
5. 사업 절·회사·접수번호/문서ID·기간·조회 시각·내용해시·추출기 리비전을 탐색 결과에 저장한다. 새 후보 추가 시 이전 기업의 자료를 보존한다. KIND 조회 실패 시에도 이미 확보한 자료와 별도로 성공한 상세 자료는 유지한다.
6. 문장/문단 단위로 질문 관련 발췌를 고르고, 회사별 최대2절/배치 전체 분량으로 모델 문맥을 제한한다. 원문 수치나 단어 중간을 잘라 새로운 근거를 만들지 않는다. 회사·문서·절·내용 리비전에 묶인 인용ID를 사용한다.
7. 최초 소개와 사업 후속 질문이 같은 자료를 사용한다. 목록의 어휘 부재를 실제 사업 부재로 단정하지 않으며, 메모리/Memory/DRAM/NAND의 확인된 제품 분류를 대조한다. 비메모리/non-memory를 메모리로 잘못 선택하지 않도록 구별한다.
8. 제조사와 장비/기판 공급의 역할을 공통 의미 심사에서 구별한다. 일반 반도체 자료를 AI 공급 근거로 확대하거나, 장비 공급을 메모리 칩 직접 제조로 바꾸는 것을 승인하지 않는다. 실제 메모리 범위 답변에서는 제조사와 관련 장비사를 구분했다.

## 발견·수정한 문제

- **실제 메모리 질문에서 SK하이닉스 누락:** 영문 DRAM/NAND 제품 목록을 한국어 문자열만으로 검사해 HPSP만 남았다. 회사별 예외 없이 제품 분류의 한·영 표현과 인용 근거를 연결하고 분야 답변의 회사 누락을 검사했다.
- **공식 웹페이지의 잡음:** Business Continuity Plan이 제품 근거로 수집됐다. 정책 페이지를 제외하고 제품 링크를 우선했다. 같은 회사의 공식 제품 하위 도메인은 허용하되 닮은 외부 도메인은 거절한다. 웹 추출 리비전을v2로 올려 예전 정책 페이지 결과를 재사용하지 않는다.
- **DART 보고서 전체 파싱 실패:** 이사회 등 다른 장의 꺾쇠 문자 표기가 사업 장까지 막았다. 회사 표지를 확인하고 사업 장만 구조를 엄격히 검사하는 별도 추출 경로를 추가했다. 삼성전자의 `< TV 시장경쟁환경 현황 >` 같은 표제는 문자 내용 그대로 보존한다. 사업 장의 잘못된 태그·DOCTYPE/ENTITY·압축/크기 제한 거절과 기존 일반 공시 파서는 유지했다. DART 추출 리비전도v2로 관리한다.
- **정상 공정명이 수치 검사에서 거절:** 2.5D·6-SIDE 같은 표기는 인용 원문의 정확한 토큰일 때만 인정했다. 2.6D·8-SIDE 등 바뀐 표기와2.5% 영업이익률은 계속 거절한다. 숫자 검증 자체를 끄지 않았다. 재작성에는 숫자를 가린 실패 문맥을 전달하고 불필요한 공정 수치를 줄이도록 했다.
- **실행 중 서버의 이전 모듈:** 디스크/독립 프로브는 새 코드였지만 실제 화면은 예전 KIND 경로를 사용했다. 화면 서버만 재시작해 새 경로를 적용했다. 이후 실제 화면에서 상세 근거 사용을 확인했다.
- **원문 발췌로 대체된 응답을 성공으로 오판할 위험:** HTTP 검수에 예외0뿐 아니라 대체 응답 여부와 상세 근거 표시 여부를 기록하도록 보강했다. 최종 입력 경로는 finished=true, exceptions=[], fallback=false, detailed_source_visible=true였다.

## 자동 검사와 실제 검수

- 최종 **전체824개/54.670초 통과**. 기존799개에 이번25개를 추가했으며 원래의 정상·오류 기대값을 완화하지 않았다.
- 관련 검사86개 통과 후 발행일 정밀도·기업 고유번호 조회의 잔여 예산 전달 검사2개를 추가해 최종 전체824개로 재검수했다. 전체824는 최종 코드 기준이며 관련88개를 별도 재실행했다고 쓰지 않는다.
- `business_context_live.json`: 실제 회사 자료 보강→사업 차이/메모리 범위 질문2개→생성·의미 심사, 대체 응답 없음. 이 기록은 DART 추출v2 적용 전의 사업 자료 스냅샷이며 실제 공개 근거/생성·심사 기록으로 보존한다. 이후 파서 개선은 최종 화면 경로에서 확인했다.
- `business_context_before_scope_fix.json`: SK하이닉스가 누락되고 정책 페이지가 포함됐던 원래 결과. 자동 의미 심사 통과만으로 실제 질문 품질 완료라 할 수 없음을 보여준다.
- `business_relation_boundaries.json`: 실제 로컬 심사에서 정상 장비 사업 설명은 승인, 메모리 제품 직접 제조라는 잘못된 주장은 거절했다. 기존 근거 일치 검증을 보존한다.
- `business_context_http_before_restart.json`: 이전 모듈을 사용한 화면 응답.
- `business_context_http_before_numeric_fix.json`: 새 자료는 연결됐지만 숫자 검사 때문에 원문 대체 응답으로 내려간 결과.
- **`business_context_http.json`:** 최신 핵심 수집/공정명 수정 후 실제8501 초기→테마 질문 실행 완료·예외0·대체 응답 아님·상세 사업 근거 표시5건 확인. 삼성전자·SK하이닉스·한미반도체의 제조/장비 역할 설명을 실제 반환했다. 브라우저 크기별 육안 검수는 아니다.
- 날짜 정밀도/비메모리 제외·남은 수집 예산 전달의 마지막 작은 변경은 최종 전체824개에 포함했다. 마지막 서버 재가동과 초기화 검수는 `business_context_server_final.json`에 별도로 남긴다. 이 작은 변경 이후 전체 금융 질문을 다시 수행했다고 쓰지 않는다.

## 아직 완료하지 않은 것

현재 답변은 plain 응답이다. 기업별 카드 스키마·제목/문단/인용 소유권의 강제 검사·구형 저장/뉴스 블록 호환은02-C, 카드/출처 팝오버·중복 표 제거·선택 행동은02-D, 전체 대화/브라우저 육안/폭별 검수는02-E에 남는다.

실제 답변에는 아직 기술 용어, 불필요한 제품 나열, 도입/결론의 반복이 남는다. 일반 배경 언급과 실제 직접 사업을 구별하는 대표 반례를 검수했지만 모든 산업/질문의 품질을 보장하지 않는다. 다음 카드 생성에서는 근거가 있는 역할·용도·테마 연결만 필요한 분량으로 구성해야 한다.

공식 HTML과 DART XML을 지원하며 이미지·스캔 PDF·자바스크립트로만 만들어지는 본문은 수집 성공으로 위장하지 않는다. 실패/빈 절 상태를 남기고 확인된 다른 자료를 유지한다. 메모리 분류 용어는 검증된 일반 제품 분류이며 회사/고객/투자 수혜의 예외 목록이 아니다. 타 분야도 확인된 표현과 근거에 따라 확장한다.

참고한 공식 규격: [DART 기업개황](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019002)의 홈페이지/IR·종목코드 필드. 제품 분류 확인: [메모리 사업 제품 설명](https://semiconductor.samsung.com/kr/about-us/business-area/memory/), [DRAM 제품 분류](https://semiconductor.samsung.com/kr/dram/). 이 일반 분류 자료를 다른 기업의 실제 사업 근거로 대신 쓰지 않는다.
