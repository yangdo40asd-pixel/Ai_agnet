## 1. 개발 배경 및 프로젝트 목표

### 1.1 개발 배경 및 목표
최근 개인 투자자의 증가와 함께 주식시장에 대한 관심이 높아지고 있으나, 기존 금융 앱은 대부분 종목명이나 종목코드를 직접 검색해야 하는 구조로 되어 있어 관심 산업이나 '테마'를 중심으로 투자 정보를 탐색하기에는 번거로움이 많다. 또한 PER 등의 지표나 최근 뉴스를 단편적으로 확인하는 것만으로는 종합적인 기업 및 테마 상황을 파악하기 어렵다.

본 프로젝트는 사용자가 'AI 반도체', '2차전지'와 같은 **관심 테마 키워드 하나만 입력하면, AI 에이전트가 관련 종목을 자동으로 탐색하고 실시간 주가·재무 지표 및 최신 뉴스를 실시간 수집하여 객관적이고 신뢰도 높은 리포트를 한 화면에서 제공**하는 것을 목표로 한다.

> **【 핵심 가치 】**  
> 사용자의 키워드 입력 하나로 관련 종목 발굴부터 팩트 데이터 수집 및 AI 해석 리포트 자동 생성

## 2. 현재 개발 진행 상황 (구현 완료 내역)

현재 전체 5단계 로드맵 중 기초 환경 구축(Phase 1), 데이터 파이프라인 기술 검증(Phase 2 PoC), 그리고 Streamlit 기반 1차 웹 인터페이스 통합(Phase 4 일부)까지 성공적으로 구현을 완료하였다.

| 단계 | 구분 | 주요 구현 내용 | 진행 상태 |
| :--- | :--- | :--- | :---: |
| **Phase 1** | **환경 구축** | Python 가상환경, 핵심 라이브러리 설치, 보안 파일(`.env`) 분리 | **완료** |
| **Phase 2** | **테마주 탐색** | Groq AI 기반 테마 입력 시 KRX 상장 대표 관련주 3개 자동 도출 | **완료** |
| **Phase 2** | **주식/재무 수집** | `FinanceDataReader`(종목코드 변환) + `yfinance`(실시간 주가/PER) 연동 | **완료** |
| **Phase 2** | **뉴스 수집** | `NAVER API HUB` (NCP 최신 규격) 연동하여 실시간 증권 뉴스 3건 추출 | **완료** |
| **Phase 4** | **웹 UI / 리포트** | Streamlit 기반 검색창, 로딩 스피너, 전문 애널리스트 톤 리포트 화면 연동 | **완료** |

## 4. 패키지 및 기술 스택 현황

현재 프로젝트 가상환경에 구축된 패키지를 실제 코드에서 사용 중인 패키지와 설치 완료 후 향후 기능 확장을 위해 사용할 예정인 패키지로 명확히 구분하여 정리하였다.

### 4.1 현재 설치 및 실제 사용 중인 패키지

| 패키지명 | 설치 및 사용 목적 |
| :--- | :--- |
| `streamlit` | 웹 UI 화면 구성 (테마 검색창, 로딩 스피너 애니메이션, 리포트 결과 출력) |
| `langchain` | AI 에이전트 오케스트레이션 및 프롬프트 파이프라인 구축 |
| `langchain-groq` | Groq 초고속 LLM API 연결 및 모델 호출 |
| `finance-datareader` | 한국거래소(KRX) 전체 상장 종목 리스트 조회 및 종목명 → 종목코드 매핑 |
| `yfinance` | 종목코드 기반 실시간 주가 및 주요 재무 지표(PER 등) 수집 |
| `requests` | NAVER API HUB(NCP) 뉴스 검색 엔드포인트에 HTTP 요청 전송 |
| `python-dotenv` | `.env` 파일에 저장된 API 보안 키(Groq, Naver 등) 안전한 로드 및 관리 |
| `pandas` | 수집된 종목 리스트 및 금융 데이터의 표(DataFrame) 형태 가공 및 정렬 |
| `beautifulsoup4 (BS)` | 정적 웹페이지 HTML 구조 파싱 및 텍스트 데이터 추출 (PoC 검증 완료) |
| `lxml` | BS HTML 파싱 처리 속도 향상을 위한 고성능 C 기반 파서 엔진 |

### 4.2 설치 완료 및 향후 사용 예정 패키지

| 패키지명 | 설치 및 도입 목적 |
| :--- | :--- |
| `opendartreader` | 금융감독원 전자공시(DART) API 연동을 통한 기업 공시 재무제표(매출, 영업이익, 부채 등) 원본 수집 |
| `selenium` | 공식 API가 미제공되는 타겟 사이트 접근 시 동적 웹페이지 크롤링, 자동 로그인 및 버튼 제어 |

| `aiohttp` | 여러 API 및 웹페이지 비동기 병렬 호출을 통한 전체 데이터 수집 응답 속도 최적화 |

## 5. 향후 개발 계획 (앞으로 구현할 목록)

1. **금융감독원 전자공시(DART) API 연동 (재무제표 확장)**
   * 현재 `yfinance`에서 일부 누락되는 재무 지표(PER 정보 없음 등)를 보완하기 위해, 발급 신청 완료된 DART API를 연동하여 기업의 실제 공시 재무제표(매출액, 영업이익, 부채비율 등)를 정확하게 수집하도록 고도화한다.

2. **코드 모듈화 및 리팩토링 (아키텍처 정립)**
   * 현재 PoC용으로 통합 작성된 코드를 기구축된 디렉터리 구조(`src/`)에 맞춰 분리한다.
     * `src/data/stock.py` (주식 데이터 수집 전담), `src/data/news.py` (뉴스 데이터 수집 전담)
     * `src/agents/report.py` (프롬프트 및 리포트 생성 전담), `src/ui/app.py` (화면 입출력 전담)

3. **동적 크롤링 및 업무 자동화(Selenium) 단계적 적용**
   * 향후 추가적인 타겟 웹사이트 중 로그인이 필요하거나 동적 스크롤 렌더링이 필수적인 데이터 출처가 발생할 경우 이미 설치된 `selenium` 및 `webdriver-manager` 모듈을 즉시 적용한다.

4. **리포트 다운로드(PDF) 및 시각화 기능 추가**
   * `ReportLab`을 활용하여 웹 화면에서 생성된 리포트를 PDF 파일로 다운로드할 수 있는 기능을 구현하고, `Plotly`를 통해 최근 주가 추이 차트를 시각적으로 함께 제공한다.
